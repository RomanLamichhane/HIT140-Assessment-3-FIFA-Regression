# HIT140 Assessment 3 — FIFA World Cup 2026 Objective 2

This repository contains a fully runnable implementation of Objective 2: two related but distinct regression tasks using FIFA World Cup 2026 match data.

## Assignment constraints implemented

- **LR2.1:** 104 rows, one row per match, exactly 8 pre-match explanatory variables.
- **LR2.2:** 208 rows, one row per team per match, exactly 8 pre-match explanatory variables.
- The two models share no more than four intended predictor concepts.
- Current-match goals, possession, shots, and other post-kick-off information are not used as explanatory variables.
- Rolling/recent-form predictors are calculated before the current fixture is added to team history.
- First-match tournament-history values use the documented neutral zero baseline.

## Baseline and rubric-enhanced analysis

The original scripts are retained for reproducibility of the original hold-out results.

The new `*_enhanced.py` scripts add:

- descriptive statistics and correlation-based EDA;
- target-distribution, correlation-matrix, and predictor-target-correlation visualisations;
- chronological 5-fold `TimeSeriesSplit` cross-validation on the training period only;
- standardisation inside regularised-model pipelines;
- systematic comparison of OLS, Ridge, Lasso and Elastic Net candidates;
- hyperparameter experiments for Ridge/Lasso/Elastic Net;
- model selection using mean cross-validated RMSE;
- bootstrap 95% confidence intervals for selected-model MAE, RMSE, and mean residual;
- top-candidate cross-validation visualisation;
- untouched chronological 20% hold-out evaluation;
- actual-vs-predicted and residual plots;
- baseline-vs-selected-model comparison outputs.

For LR2.2, cross-validation is performed using **match IDs**, keeping the two rows from each match together.

## Run everything on Windows

1. Install Python 3.10+.
2. Open Command Prompt/PowerShell in the repository root.
3. Run:

```powershell
python -m pip install -r requirements.txt
RUN_ALL_WINDOWS.bat
```

Cross-platform alternative:

```powershell
python run_all.py
```

Or run manually:

```powershell
python build_datasets.py
python Raman_Regression_2_1_Goal_Difference\code\raman_regression_2_1.py
python Saroj_Regression_2_2_Goals_Scored\code\saroj_regression_2_2.py
python Abhinav_Data_Validation_Model_Comparison\code\abhinav_validate_datasets.py
python Abhinav_Data_Validation_Model_Comparison\code\abhinav_model_comparison.py
python Raman_Regression_2_1_Goal_Difference\code\raman_regression_2_1_enhanced.py
python Saroj_Regression_2_2_Goals_Scored\code\saroj_regression_2_2_enhanced.py
python Abhinav_Data_Validation_Model_Comparison\code\abhinav_enhanced_model_comparison.py
```

## Important interpretation note

A more complex or regularised model is not automatically better. The selected model is chosen by time-aware cross-validation on the training period, then evaluated once on the untouched hold-out period. If optimisation fails to improve hold-out performance, report that result transparently rather than claiming an improvement.
